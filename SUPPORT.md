# Support

mevo2glpi est un projet sous EUPL 1.2 proposé pour évaluation et
capitalisation. Aucun SLA, astreinte ou engagement de support public n'est
fourni.

## Demande non sensible

Utiliser les issues GitHub pour :

- un défaut reproductible avec des données synthétiques ;
- une question sur la documentation ou la compatibilité ;
- une proposition d'amélioration générique.

Indiquer le tag ou SHA, l'environnement, le composant concerné, le résultat
attendu et un diagnostic expurgé. Ne jamais joindre de fichier audio réel,
secret, certificat, URL interne ou donnée personnelle.

## Sécurité et incidents

Les vulnérabilités, secrets exposés et incidents ne doivent pas être publiés
dans une issue. Suivre [`SECURITY.md`](SECURITY.md).

## Déploiement dans un autre établissement

Le [guide d'adoption](docs/adoption.md) définit la compatibilité qualifiée, les
adaptations attendues et le parcours d'évaluation. Chaque établissement reste
responsable de sa recette, de son analyse de risques, de son exploitation et
de sa conformité.
